Продвижение бота: посевы в Telegram

Пример пакета на готовом боте. Бот: тест из трёх вопросов с баллами, результат зависит от ответов, в конце гайд «Масштаб вырос, а вы всё ещё управляете по-старому». Ваше время: около 30 минут на запуск, дальше только ожидание.

Это образец для показа. Ссылка на бота, список каналов и цены ниже помечены как заполняемые: их я подставляю после согласования ниши и бюджета. Цифр конверсии нет, я их не обещаю: они появятся после первых размещений.

Что вы получаете от меня

  • Таблицу каналов с критериями отбора и приоритетом.
  • Три готовых рекламных поста для проверки на разных каналах.
  • График размещений: один канал в день, чтобы приход людей был виден по каналам.
  • Разбор результата через 3–5 дней: куда докупать, что отключить.

Инструкция

1

Пополните баланс на бирже рекламы. Для примера: Telega.in, вход через Telegram, раздел «Баланс». Для старта хватит бюджета на 5–8 размещений, точную сумму назову по ценам каналов из таблицы.

2

Закажите размещения по таблице.

  1. Возьмите первую строку таблицы «Каналы» ниже и найдите этот канал на бирже.
  2. Нажмите «Купить рекламу» и вставьте пост из колонки «Пост» (кнопка «Копировать»).
  3. Вставьте ссылку на бота, она одна для всех постов. Саму ссылку не меняйте.
  4. Выберите дату из колонки «Дата» и отправьте на согласование. Даты не сдвигайте: по ним я считаю результат каждого канала. Повторите для остальных строк.
3

Напишите мне «готово» через 3–5 дней. Остальное сделаю я: статистика по каналам, цена результата, решение о докупке.

Если админ канала просит правки или отказывает, пришлите мне его сообщение. Я подготовлю ответ.

Что мы измеряем

  • Клики по размещению: данные биржи по каждому каналу.
  • Новые пользователи бота по дням: выгрузка из бота. Метки в ссылках бот не принимает, поэтому каналы разводим по датам: один канал в день.
  • Написавшие вам после гайда: видите только вы, бот сообщений не принимает.

Показатель, по которому решаем, куда докупать: цена одного человека, дошедшего до гайда, по каждому каналу.
